# Командный проект: Интерактивная мини-игра на Vue 3 + Vite

Браузерное SPA-приложение (мини-игра), разработанное в составе команды из 3 студентов. Проект демонстрирует навыки работы с реактивным состоянием приложения, пользовательскими событиями и продвинутое владение инструментами командной разработки.

## 🚀 Стек технологий
* **Core:** Vue.js 3 (Composition API)
* **Стилизация:** HTML5, CSS3
* **Инструменты сборки:** Vite
* **Контроль версий & Командная разработка:** Git, GitHub (совместная работа с удаленных рабочих станций, слияние веток через `git merge`, разрешение конфликтов слияния)

## 🛠 Функционал и особенности
* **Игровая логика:** Динамический просчет игровых событий на стороне клиента, запуск таймеров, реактивный подсчет очков и условий победы/проигрыша средствами Vue 3.
* **Совместная разработка:** Разработка велась распределенно. В рамках проекта я выступал в роли 
  **Team Lead**: координировал процесс, распределял задачи между участниками, отвечал за итоговую сборку проекта на Vite, регулярный мёрдж веток (`git merge`) и ручное разрешение конфликтов кода при слиянии.

## 💻 Локальный запуск проекта

1. Клонировать репозиторий:
```bash
git clone https://github.com/Libibe-git/tEAMOCHKA.git
```

2. Перейти в папку проекта:
```bash
cd tEAMOCHKA
```

3. Установить зависимости:
```bash
npm install 
```

4. Запустить проект:
```bash
npm run dev
```
